## Известные ограничения
- Тестовый каталог — только Creative Commons; лицензированного каталога нет (нужны договоры).
- iOS собирается только через облако (EAS) — Mac отсутствует.
- На диске C: ~18 ГБ свободно.
- Все инструменты разработки — в `B:\develop` (кроме Docker Desktop, WSL, Python 3.14 и VS Build Tools 2022 на C:).
- Проверить руками в обычном браузере: выбранная тема (светлая) не пережила перезагрузку в браузере автоматизации. Код (`lib/theme.ts`) выглядит верным, а браузер автоматизации сам вмешивается в страницу (подставляет атрибуты `data-agent-id`, из-за чего Next.js показывает ошибку гидратации), так что, скорее всего, это его особенность.
- `setup.bat` надо запускать при остановленном `dev.bat`: smoke-тестам нужны свободные порты 3000 и 4000.
- В dev-БД есть тестовый аккаунт `qa-i3-2152@remusic.local` (пароль `QaReset-2026-newpass`).
