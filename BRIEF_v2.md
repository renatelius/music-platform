# PROJECT: NEXT-GENERATION GLOBAL MUSIC ECOSYSTEM

## 1. МИССИЯ

Ты создаёшь музыкальную технологическую платформу нового поколения — полноценную экосистему, которая должна стать новым стандартом музыкальных приложений.

Это международный продукт, объединяющий лучшие возможности Spotify, Apple Music, YouTube Music, Tidal, Deezer, SoundCloud и Яндекс Музыки.

Но конечная цель — не повторить их.

Нужно создать продукт, который предлагает принципиально лучший пользовательский опыт, собственную технологическую инфраструктуру, интеллектуальные рекомендации и универсальную музыкальную библиотеку.

Работай как объединённая команда ведущих мировых разработчиков, дизайнеров, архитекторов и музыкальных инженеров.

## 2. ЦЕЛЕВЫЕ ПЛАТФОРМЫ

Создай четыре полноценных клиента:

1. Web — современное браузерное приложение.
2. Windows — полноценное настольное приложение.
3. Android — мобильное приложение.
4. iOS — мобильное приложение.

Все платформы должны использовать общую backend-инфраструктуру.

Обязательная синхронизация:

- Аккаунт.
- Музыкальная библиотека.
- Плейлисты.
- Любимые композиции.
- История прослушивания.
- Рекомендации.
- Настройки.
- Подписка.
- Очередь воспроизведения.
- Прогресс прослушивания.

Пользователь должен иметь возможность начать слушать музыку на Windows, продолжить на смартфоне и открыть тот же плейлист в браузере.

Спроектируй TypeScript-first архитектуру с общими компонентами и бизнес-логикой.

## 4. ГИБРИДНЫЙ МУЗЫКАЛЬНЫЙ КАТАЛОГ

Создай три независимых, но объединённых источника музыки.

### A. Лицензированные каталоги

Подготовь архитектуру подключения официальных музыкальных поставщиков.

Предусмотри:
- API-интеграции.
- Метаданные.
- Обложки.
- Исполнителей.
- Альбомы.
- Плейлисты.
- Доступность композиций.
- Территориальные права.
- Условия воспроизведения.

Не считай наличие API автоматически разрешением на самостоятельную ретрансляцию музыки.

### B. Независимые исполнители

Создай Artist Studio — личный кабинет музыканта.

Возможности:
- Регистрация исполнителя.
- Загрузка аудиофайлов.
- Загрузка обложек.
- Создание альбомов.
- Управление дискографией.
- Управление релизами.
- Статистика прослушиваний.
- Информация об аудитории.
- Управление правами на собственный контент.
- Возможность монетизации.

Добавь систему проверки прав на загружаемый контент и модерацию.

### C. Личная музыкальная коллекция

Пользователь может:
- Загружать собственную музыку.
- Создавать персональную библиотеку.
- Добавлять локальные файлы.
- Импортировать существующие плейлисты.
- Синхронизировать доступные файлы между устройствами.
- Редактировать теги и обложки.
- Создавать плейлисты из собственной коллекции.

Не смешивай локальные файлы с лицензированным потоковым каталогом без соответствующей маркировки.

## 5. ЕДИНЫЙ ДИЗАЙН

Создай собственную Design System.

Визуальный ориентир:
- Премиальность Apple Music.
- Удобство Spotify.
- Информативность Tidal.
- Гибкость YouTube Music.
- Минимализм современных технологических продуктов.

Но создай самостоятельную визуальную идентичность.

Обязательно:
- Dark Mode.
- Light Mode.
- Адаптивный интерфейс.
- Плавные анимации.
- Динамические обложки.
- Красивые карточки альбомов.
- Интерактивный плеер.
- Единая система компонентов.
- Поддержка разных размеров экранов.

Продумай дизайн каждой платформы отдельно, сохраняя общую визуальную систему.

## 6. ИНТЕЛЛЕКТУАЛЬНАЯ МУЗЫКАЛЬНАЯ СИСТЕМА

Создай собственный Recommendation Engine.

Раздели рекомендации на несколько подсистем:
- Personal Discovery.
- Daily Discovery.
- Mood Discovery.
- Artist Discovery.
- Genre Discovery.
- Global Discovery.
- Similar Tracks.
- Hidden Gems.

Разработай AI DJ, который понимает естественный язык.

Примеры запросов:
- «Найди музыку с атмосферой Radiohead».
- «Хочу японский рок с эмоциональным вокалом».
- «Подбери музыку для ночной поездки».
- «Найди исполнителей, которых почти никто не знает».
- «Музыка, похожая на эту композицию, но более меланхоличная».

ИИ должен работать с реальными метаданными музыкального каталога, а не выдумывать существующие композиции.

## 7. ЕДИНЫЙ АУДИОПЛЕЕР

Разработай отдельный Audio Engine.

Требования:
- Gapless Playback.
- Crossfade.
- ReplayGain.
- Эквалайзер.
- FLAC.
- AAC.
- ALAC.
- MP3.
- Opus.
- Lossless.
- Hi-Res при наличии исходного материала.
- Очередь воспроизведения.
- Офлайн-режим.
- Синхронизация между устройствами.
- Тексты песен.
- Поддержка внешних аудиоустройств.

Плеер должен быть одинаково надёжным на всех платформах, но использовать оптимальные нативные механизмы воспроизведения там, где это необходимо.

## 8. МЕЖДУНАРОДНАЯ ЭКОСИСТЕМА

Требования:

Не создавай искусственных географических блокировок внутри собственного продукта.

Не обходи DRM и ограничения правообладателей.

## Рекомендации заказчика по старту

Не стоит сразу строить Spotify на миллион пользователей. Сначала нужно создать качественное ядро, которое можно расширять без переписывания.

Первый большой рубеж — **единый аккаунт + музыкальный каталог + настоящий плеер + синхронизация на четырёх платформах**.

После этого уже можно наращивать собственные рекомендации, Artist Studio, международный каталог и социальные возможности.

И самое важное: **не экономить архитектурно на музыкальном движке. Именно он будет сердцем всего продукта.**
