## Что это значит для ближайших итераций
- **I6 (плеер):** нижний плеер на всю ширину на десктопе (реф. 1) и полноэкранный плеер (реф. 2): обложка, прогресс, перемотка, громкость, очередь; на телефоне — мини-плеер над нижней навигацией.
- **I7 (библиотека):** «Любимые», плейлисты, недавно прослушанные в боковой панели (реф. 1, 4), лайк у трека в списках и в плеере.
- **Главная:** крупный «альбом дня» и таблица треков (реф. 1) — когда будут обложки и данные прослушиваний; сейчас разделы честно основаны на том, что есть.
