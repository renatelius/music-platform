## Рубеж 1 — «Первый контрольный результат» (BRIEF_v2 §15) · Phase 1–2 · ~4–6 недель

Критерии готовности (все 8 обязательны):
1. ✅ Регистрация и авторизация работают (I2b).
2. Главная страница рабочая.
3. Поиск по реальному тестовому каталогу.
4. Страница альбома.
5. Полноценный аудиоплеер с разрешённым тестовым аудио.
6. Создание плейлиста.
7. Сохранение любимой композиции.
8. Синхронизация аккаунта с backend (изменения видны на втором открытом клиенте).

## Зависимости и риски

| Риск | Влияние | Мера |
|---|---|---|
| Нет лицензий мейджоров | Каталог ограничен CC + независимыми | Позиционирование Universal Library; адаптер DDEX готов заранее |
| Мало места на C: (18 ГБ) | Android SDK/эмуляторы не поместятся | SDK и AVD — на B:; очистка C: перед Phase 3 |
| iOS без Mac | Нельзя отлаживать нативный модуль локально | EAS Build + физическое устройство / облачный Mac |
| Лицензия мобильного плеера | Платная зависимость | ADR-010: свой Expo-модуль |
| Тексты песен | Нужна лицензия издателей | Отложено до договора с провайдером |
| UGC-пиратство | Юридический риск | Fingerprinting + модерация до открытия загрузок |
