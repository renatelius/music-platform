## Рубеж 1 — «Первый контрольный результат» (BRIEF_v2 §15) · Phase 1–2 · ~4–6 недель

1. Регистрация и авторизация работают.
2. Главная страница рабочая.
3. Поиск по реальному тестовому каталогу.
4. Страница альбома.
5. Полноценный аудиоплеер с разрешённым тестовым аудио.
6. Создание плейлиста.
7. Сохранение любимой композиции.
8. Синхронизация аккаунта с backend (изменения видны на втором открытом клиенте).

## Phase 3 — Multi-platform · ~5–7 недель
- Windows: Tauri 2 оболочка на `app-shell`, хранение токенов в Credential Manager, медиаклавиши, автообновление, установщик.
- Android/iOS: Expo-приложение, `audio-native` (решение ADR-010), фон и экран блокировки, EAS-сборки.
- Handoff между устройствами, список устройств, вход через Google/Apple.
- Нужно от заказчика: Apple Developer, Google Play Console, аккаунт Expo; JDK 17 + Android Studio на ПК.

## Phase 4 — Hybrid Catalog · ~6–8 недель
- Artist Studio: профиль, загрузка релизов, права, модерация, статистика.
- Личная коллекция: загрузка своих файлов, редактор тегов/обложек; локальные файлы в Windows-клиенте.
- Chromaprint/AcoustID-проверка дубликатов и прав; процедура жалоб.
- Адаптер лицензированных поставщиков (DDEX ERN) — каркас и тестовая поставка.
- Admin Studio v1 + RBAC.
- Импорт плейлистов (Spotify/Apple/YouTube через официальные API → сопоставление с каталогом).

## Phase 5 — Intelligence · ~6–8 недель
- ML-сервис: аудио-эмбеддинги и признаки (темп, энергия, настроение), pgvector.
- Подсистемы рекомендаций (Personal/Daily/Mood/Similar/Hidden Gems) с объяснением «почему».
- AI DJ на естественном языке — только по реальным метаданным каталога.
- Статистика, Music DNA, Timeline. OpenSearch для текстов и фасетов.

## Phase 6 — Ecosystem · ~6–8 недель
- Социальный слой с приватностью, совместные плейлисты и комнаты.
- Подписки: Free/Premium/Family/Student, веб-платежи + биллинг магазинов приложений.
- Деплой: регионы, CDN, автомасштабирование, мониторинг, бэкапы.

## Phase 7 — Production · ~4–6 недель
- Аудит безопасности, нагрузочные тесты, оптимизация.
- Подпись и публикация: Web, Microsoft Store / установщик, Google Play, App Store.

## Зависимости и риски

| Риск | Влияние | Мера |
|---|---|---|
| Нет лицензий мейджоров | Каталог ограничен CC + независимыми | Позиционирование Universal Library; адаптер DDEX готов заранее |
| Мало места на C: (18 ГБ) | Android SDK/эмуляторы не поместятся | SDK и AVD — на B:; очистка C: перед Phase 3 |
| iOS без Mac | Нельзя отлаживать нативный модуль локально | EAS Build + физическое устройство / облачный Mac |
| Лицензия мобильного плеера | Платная зависимость | ADR-010: свой Expo-модуль |
| Тексты песен | Нужна лицензия издателей | Отложено до договора с провайдером |
| UGC-пиратство | Юридический риск | Fingerprinting + модерация до открытия загрузок |
